🩺 NurseMemo

A local AI nursing study assistant built with Tether's QVAC SDK.

NurseMemo uses on-device AI to turn nursing study material into study notes and practice quiz questions.

🚀 App

App URL: http://localhost:3000/

🔗 GitHub Repository

Repository: https://github.com/chonestradacoc-ctrl/NurseMemo

🤖 QVAC

NurseMemo uses:

QVAC SDK: @qvac/sdk 0.19.1
Function: loadModel()
AI: Llama 3.2 1B Instruct Q4_0
Inference: On-device
▶️ Run
npm install
node server.js

Then open:

http://localhost:3000/

📸 App

Run the app at the URL above and view the generated AI study notes and quiz questions.
